# smoothie_drift

Projeto base em C# (console) criado em `__smoothie_drift`.

## Estrutura

- `smoothie_drift.csproj`: arquivo de projeto .NET.
- `smoothie_drift.cs`: arquivo principal do programa.

## Requisitos

- .NET SDK 8.0 ou superior.

## Como executar

```bash
dotnet run
```

## Como compilar

```bash
dotnet build
```
